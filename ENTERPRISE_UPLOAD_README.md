# HMG Academy CBT Enterprise Upload Package

This folder is ready to upload to a GitHub repository or static hosting platform.

## Start Pages

- `index.html` — public landing page
- `teacher.html` — teacher dashboard
- `student.html` — student exam portal
- `admin.html` — enhanced enterprise admin panel
- `feature_guide.html` — complete feature explanation
- `deployment_validator.html` — deployment readiness checker

## Important

- Use Supabase anon public key only.
- Never place a service_role key in frontend files.
- Run the SQL setup guide before live use.
- No AI API is required or used.

## Suggested Deployment

1. Push this folder contents to GitHub.
2. Enable GitHub Pages or connect the repo to Cloudflare Pages/Vercel/Netlify.
3. Set Supabase Auth redirect URLs to your deployment domain.
4. Open `deployment_validator.html` after deployment.
5. Open `admin.html`, login, and run Security & Deployment checks.
